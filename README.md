## About Me

I am a Deep Learning Engineer specializing in Computer Vision, Medical Image Analysis, and Generative AI. I focus on building end-to-end automated pipelines, from complex data registration to deploying state-of-the-art models for real-world enterprise and healthcare applications.

- 🔬 **Expertise:** Architecting multi-stage pipelines using **Meta's SAM 2, SegFormer, DCLGAN, and Pix2Pix**.
- ⚙️ **Engineering:** Managing complete data lifecycles, pixel-by-pixel alignment (QuPath, Fiji), and custom image enhancement algorithms for noisy/blurry datasets.
- 🧠 **Current Focus:** Advanced generative architectures, LLMs, Retrieval-Augmented Generation (RAG), and agentic systems.
- 📫 **Reach me at:** ahmedraza8616@gmail.com
